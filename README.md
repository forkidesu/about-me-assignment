# About Me Assignment

A simple website about Osama and Maab for the Software Maintenance Lab 7 assignment. The project uses HTML and CSS to practice working together with GitHub branches, commits, and pull requests.

## Features

- One About Us section with separate information about Osama and Maab.
- Lorem ipsum placeholder text for both people.
- A black background with white text.
- Centered content with spacing between the two profiles.

## Team

## How to Open
